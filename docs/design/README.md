# Gestaltung des Atlas

Grundlage ist die vom Projekt bereitgestellte Datei `index(2).html`, **Apperception Machinery · BrandBook V0.2**. Abschnitt 12 der Spezifikation beschreibt die Übertragung auf den Atlas.

`tokens.css` ist eine kleine Startzuordnung der Referenzwerte. Sie ist keine vollständige Komponentenbibliothek und bestätigt noch keine Kontrastprüfung aller Zustände. Liberation-Fontdateien müssen später mit ihrer tatsächlichen Version und Lizenz vendoriziert werden; dieses Paket enthält keine Fontdownloads.

Desktop: dunkle Navigation links, Globus als Hauptfläche, Suche oben, Zeit unten, Details bei Auswahl rechts. Netz und Objektbetrachter verwenden dieselbe App-Schale. Die Navigation bildet redaktionelle Einstiege ab; sie zwingt die historischen Beziehungen nicht in einen einzigen Baum.

Kartenfarben und Bedienungsfarbe erfüllen verschiedene Aufgaben. Auswahl, Unsicherheit und Gebietsanspruch brauchen zusätzlich Kontur, Muster oder Text. Keine dauerhaft bewegte Hintergrundszene; respektierte reduzierte Bewegung und klare Tastaturpfade gehören zur Umsetzung.
